## Root cause (source-verified on 930d49e5)
- `dispatchSpawnRequest` (workspaces.ts:1580) -> `startWorkspaceAgentHeadless(ws.id)` (1646).
- `startWorkspaceAgentHeadless` (1389): `if (ws.lastTask && await sdkStartAndDeliver(...)) { ... return; }`
  — the DEFAULT structured/agent-sdk surface; returns WITHOUT calling startAgentPty.
- `maybeStartRunAtAnchor` (run creation) + `writeBusSwitchState` (notice) are wired ONLY into:
  - `startAgentPty` (4547/4555) — called from api-handlers ptyStart (RAW PTY tab, 839),
    restart-workspace (77), migrate-resume (2554). NOT the default spawn.
  - `startRunForPromoted` (4722) — the /promote path only (run-start, no notice).
- => a normal structured spawn creates neither the run row nor the notice. A run/notice appears
  ONLY if the user opens the Raw PTY tab, restarts, or migrates. The canary reproduces.
