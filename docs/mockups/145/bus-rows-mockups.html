#145 — Bus wake orders & deliveries as first-class rows

Three selectable mockups. Each shows the SAME canary exchange rendered by both new row families: a wake row (marker-keyed on WAKE_ORDER_HEADER, collapsed→expandable to the ordered commands) and a delivery row (an orchestra check tool card folded into a lot view with an ACKED/PENDING badge that flips on the matching ack). For contrast, the "must-FAIL control" line at the bottom of each pane is a plain human turn containing the words "lot pending" — it must render as an ordinary bubble, NOT a wake row. Dark theme uses the real --av-* tokens.

Variant A — "quiet rows" (peer-family idiom, #56/#64 lineage)

Borderless tinted rows in the same family as the existing peer/inbox compact rows. Wake = amber bell chip line; delivery = a bordered card that expands to a per-message grid. Lowest visual weight — reads as fleet traffic, not conversation.
