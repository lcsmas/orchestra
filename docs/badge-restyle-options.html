Sidebar badges — release tags, unpushed count, MERGED

Real sidebar chrome, real tokens, real rows. The PR and Linear badges are already flat inside a row — .ws-item .pr-badge strips border, background and padding, leaving a bare 10px glyph + 9px mono number. The release and unpushed pills never got that treatment: they still carry a filled track and a 1px border, which is why they read one size up. Every option below removes the MERGED pill.

What each option decides

  • A — pure consistency. One glyph + number language for every badge in the strip. Longest strip when a branch shipped in 3 releases.
  • B — same, but one tag glyph for the whole run and older versions dimmed. Reads as “this shipped, latest is X”.
  • C — shortest. Latest version + +N, full list on hover, mirroring how extra PRs already collapse.
  • D — keeps an outline chip, just lighter and PR-badge sized. Choose if you want release tags to stay visually separable from PR/Linear links.

All four drop the MERGED pill. Note it is already conditional — it renders only when there is no merged-PR badge — so removing it costs no information on rows that have a PR linked. Unpushed ↑2 becomes an arrow glyph + count in A/B/C/D (matching how PR/Linear pair a glyph with a number) rather than a text arrow inside a chip.
