## 1. Method, conventions, instruments

**Evidence classes** — every number below carries one:
- **MEASURED** — produced by a command in §8 against the build in this tree; raw output in `docs/research/hidden-cost-inventory/evidence/` (file named beside the number). Rendered tables are generated by `scripts/hidden-cost/render-tables.py` from that directory; no figure in this document was typed from memory.
- **FIELD** — read-only observation of the live machine's own Orchestra (`/proc`, `store.json`, log); a single sample, lower bound when stated.
- **CODE** — read from source; the site is cited `path:line` and verified by `scripts/hidden-cost/check-anchors.py`. A CODE claim is a mechanism, not a cost.
- **UNMEASURED** — listed in §7 with the reason. Never an estimate passed as measured. **EXTRAPOLATED** = a measured per-unit rate × a stated field count; the formula is printed.

**Enumeration.** `bash scripts/hidden-cost/enumerate.sh` prints the hit count of every grep category used to find a site; `--list <category>` prints every `file:line`. Both are committed as `evidence/enumeration-*.txt` (categories: SDK/CLI control requests, `query()`/spawn bridge, child-process spawns incl. promisified wrappers and `simple-git`, PTYs, `fetch`/`http`/`net`/WebSocket, auto-updater, `setInterval`, `setTimeout`, file watchers, `requestAnimationFrame`, infinite CSS animations, `npx`/`@latest`, `git fetch/pull/push`, `gh`, `/proc` readers, hook events). Two categories are *audited zeros*: `net-updater` = 0 and `npx` = 0 hits in `src/` (the `npx …@latest` class lives in user/repo MCP config — §4.D); `proc-exec` lists 35 hits that are `RegExp#exec`/`db.exec` — none imports `child_process.exec` (`grep -c child_process` over the list = 0).

**Instrument defects found and fixed during this work (each would have shipped a plausible wrong number):**
1. RSS via `statm × 4` reads **4× low on this 16 KB-page host** (`getconf PAGESIZE`=16384) — review F1 of C7b; now `VmRSS` from `/proc/<pid>/status` (control: on the reader's own pid VmRSS 50 048 kB vs `statm pages × 16` 50 064 kB, ratio to the old formula 4.00). **Every RSS in this document was re-measured after the fix; the pre-fix runs are discarded.**
2. The first `gh` stub printed `[]` for `--jq` calls, so the app ran `git rev-parse undefined^{commit}` once per release call (86 spurious spawns in a 360 s run) — stub now prints nothing, like real `gh --jq` on an empty list.
3. `swaymsg [pid=…]` cannot address a window from inside a pid namespace (sway sees the host pid): the first "hidden window" run never hid anything and read like a real hidden-window result. The hide is now proven by sway's own `get_tree` (`visible:false`) and the run is VOID without it.
4. `hook-cost` originally ran hooks with `spawnSync` while the hooks server lives in the same node process → every `curl`/`orchestra whoami` hook waited its 30 s timeout (a fabricated "35 s hook"). Async spawn now; the `orchestra` CLI leg is measured separately and live (§4.E).
5. C1's launcher and mine **refuse at load > 20 (D7)**: four scenario runs were refused at load 30 and re-run, not reported.
6. `--hooks 0` does **not** remove hooks: `agent-sdk` installs them itself at session start. The "no-hooks" scenario is therefore a *replicate* of the base run and is used only as a run-to-run noise estimate.
